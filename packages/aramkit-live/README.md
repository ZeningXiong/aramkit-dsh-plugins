# 海斗助手在线版

DSH Web UI 插件，连接本机 League Client 的 LCU 只读接口，数据来自 [ARAMKit](https://aramkit.cn/zh-CN)。

## 功能

- **选人阶段**
  - 读取当前共享备选席和你的当前英雄，列出这一局可选的英雄。
  - 按 ARAMKit 英雄胜率排序，标出胜率最高的 5 个。
  - 读取五名队友的 `昵称#Tag`，查询隐藏分、表现分。
  - 识别你当前选择的英雄，自动加载出装顺序、召唤师技能和海克斯推荐。
  - 支持暴击 / 战士 / 特效等流派切换，每个流派有独立的核心装备路线。
  - 海克斯按品质切换，默认前 3，可展开前 15，并显示高胜率海克斯组合。
- **对局进行中**
  - 只保留你自己选择的英雄，切出游戏也能继续查看。
  - 显示当前英雄的出装、召唤师技能和海克斯。
  - 如果没有选人缓存，会从游戏内 Live Client API 读取当前阵容并定位你自己。
- **对局结束**
  - 读取 LCU 结算面板，展示友方五人的 KDA、伤害、经济等。
  - 等待 match history 同步本局海克斯，表格显示每人选择的海克斯图标，悬浮可看名称、品质和说明。
  - 调用 DSH 当前默认模型，生成友方五人的 AI 锐评：谁尽力、谁犯罪、谁不团队，并结合海克斯选择合理性。
  - 治疗只统计对队友的治疗，自身吸血/自愈不计入团队贡献。
  - AI 锐评可以关闭，关闭后只显示结算面板，不消耗 Token。
  - 页面右上角有 AI 锐评开/关，也可以在进游戏前关闭。
  - 支持毒舌、教练、抽象、数据复盘等风格，以及自定义语料/风格要求。
  - 内置三套语料预设：虎扑毒舌、海斗专业分析、专业抓处；选中后自动切到「自定义」风格，语料仍可继续编辑。
  - AI 结果按对局、风格和语料缓存 30 分钟。
- **对局记录**
  - 结算出现时自动跳到「对局记录」并打开这一局，不用怕开下一局把锐评弄丢。
  - 记录当天对局，保留 24 小时：胜负、时长、你的英雄和 KDA、五人结算表、该局锐评。
  - 锐评改由宿主在结算时后台生成，生成完写进记录；切页面、开下一局都不影响。
  - 记录存在 `%USERPROFILE%\.dsh\aramkit-live\history.json`（遵循 `DSH_HOME`），过期自动清理。
  - 顶部「本局 / 对局记录」可以随时切换。

## 使用

1. 保持 League 客户端和 DSH 在同一台 Windows 机器上。
2. 打开插件后进入选人阶段，页面会自动刷新。
3. 如果提示未连接：
   - 确认客户端已启动并登录。
   - 插件会自动从 `LeagueClientUx.log` 恢复端口和令牌；WeGame 客户端的 `LeagueClient\lockfile` 经常是 0 字节，这是正常的。
   - 如果自动恢复失败，可在页面的「手动指定 lockfile」里填入有效的 `lockfile`，或设置环境变量 `ARAMKIT_LCU_LOCKFILE`。
   - 也可以尝试自动从 `LeagueClientUx.exe` 命令行读取端口和令牌。

## 边界

- LCU 是 Riot 未公开的本地接口，可能随客户端版本变化。
- 只读，不修改客户端文件、不注入游戏进程、不读取游戏内存。
- 隐藏分只覆盖国服；队友名称不可见、人机或未收录时显示“未收录”。
- “可选英雄”指当前候选池（共享备选席 + 你当前英雄），不是全部 173 个英雄。
- AI 锐评需要 DSH 已配置默认模型；只评价友方，不评价敌方。
- 对局记录只保留最近 24 小时，靠插件页轮询结算来落盘；关掉 DSH 面板期间结束的对局不会记录。
- 本插件不是游戏内悬浮窗，需要在 DSH 面板中查看。

## 实现

- `lcu.js`：lockfile/进程命令行发现、本地 HTTPS Basic Auth、LCU 只读请求。
- `data.js`：ARAMKit 英雄、隐藏分、出装、海克斯数据。
- `index.js`：选人/结算状态、队友 MMR、AI 锐评、对局记录持久化和同源 HTTP 路由。
- `client.js`：侧栏 `sidebar.panellist` + `main` 面板（本局 / 对局记录）。
