# 海斗助手隔离版

DSH Web UI 插件，数据来自 [ARAMKit](https://aramkit.cn/zh-CN)。

## 功能

- **队伍隐藏分**：输入自己的 `昵称#Tag`，读取最近一局海克斯大乱斗同队五人的隐藏分、表现分和本局 KDA；也可以手动逐个查询队友。
- **英雄推荐**：选择英雄后查看出门装、核心三件套、鞋子、后续装备和备选核心；可在「全分段 / 高分段」之间切换统计口径。
- **召唤师技能与加点**：展示胜率最高的召唤师技能组合和技能主加顺序。
- **海克斯前三名**：用「棱彩 / 黄金 / 白银」三个标签切换品质，每次只看一种，避免并排拥挤；默认展示该品质前 3 名，点击右侧箭头展开前 15 名，再点收起。

## 使用

安装后在左侧栏底部点击六边形「海斗助手隔离版」图标，或从侧栏面板列表打开。页面右上角的 `EN / 中文` 可以切换界面语言，默认中文。

- 隐藏分查询覆盖国服，接口与 ARAMKit 的查询页一致。
- 海克斯默认过滤少于 200 场的样本；出装默认过滤少于 500 场的样本。
- 数据版本、更新时间和样本量均来自 ARAMKit 的公开数据端点。

## 实现

- Host 半：`index.js` 注册 `/aramkit-api/*` 同源路由，代理 ARAMKit 的隐藏分接口并裁剪英雄静态数据，避免浏览器 CORS 限制。
- Client 半：`client.js` 注册 `sidebar.panellist` 与 `main` 两个 slot，使用 DSH 主题变量和 locale 服务渲染页面。
- 资源：`icon.svg` 为插件图标，`locale/*.json` 提供插件管理器中的中英文标题与描述。
